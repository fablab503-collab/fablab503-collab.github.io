dcreations.fr moves to GitHub Pages

27 October 2026

Since 27 October 2026, the dcreations.fr website is hosted by GitHub Pages (GitHub, Inc.).

What stays the same:

  • It is still a static site built with Astro: plain, fast HTML pages.
  • It still has no cookies, no analytics and no trackers.

What changes:

  • GitHub provides the secure connection (HTTPS). Like any host, it processes your IP address and keeps technical logs.
  • Cloudflare only provides DNS for the domain name: your visits do not go through Cloudflare.
  • The chat with the AI assistant team is paused, because GitHub Pages only serves static files. To reach me: contact@dcreations.fr or +33 6 95 91 36 09.

The legal notice and the privacy policy are up to date.
