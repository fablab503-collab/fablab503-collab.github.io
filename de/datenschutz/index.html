Beim Besuch der Website

Diese Website verwendet keine Cookies, keine Statistik, keine Werbung und keine Formulare. Sie lädt nichts von anderen Websites (keine externen Schriften, Videos oder Skripte).

Ihr Browser speichert nur auf Ihrem Gerät die gelesene Sprache und Ihre Wahl „angestellt“ oder „freiberuflich“. Diese Angaben werden nie übertragen.

Die Website liegt auf meinem eigenen Server in Frankreich, der keine Besucherprotokolle speichert.
