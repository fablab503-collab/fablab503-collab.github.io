                  About these numbers

                  Cookieless. A visitor is one browser on one network on one day: the code changes every day, so "visitors" over 30 days counts a person who came on 3 days 3 times, and a phone moving from Wi-Fi to 4G can count twice. Bots, scripts and browsers that ask not to be tracked (GPC / Do Not Track) are left out. Country and city are Cloudflare's estimate. Single page views exist for today only; finished days are kept as daily totals for 400 days. Changes compare with the same number of days just before; today is still running, so it pulls the change down until evening. No change is shown for Today, or when the days before are no longer kept.
