Int4 Block Quant Inspector

Pack 32 float weights into 4-bit nibbles behind one shared FP16 scale per block (Q4_0), or into 256-weight super-blocks with 6-bit sub-scales (Q4_K style), and measure the MSE loss.

Controls

Everything recalculates live and works fully offline — no network, no keys. Settings and custom weights are saved in this browser only (localStorage) and never sent anywhere. Loading custom weights replaces the generated set; changing a generator setting goes back to generated weights.

How it works

  • Q4_0 block — 32 weights → 18 bytes. The weight with the largest absolute value (sign kept) gives the scale d = max / −8, stored as one FP16 (2 bytes). Each weight becomes a nibble q = clamp(round(w/d) + 8, 0, 15); two nibbles per byte, low nibble first → 16 bytes. Dequantize: ŵ = (q − 8) · d.
  • Codes span −8…+7. One extreme of each block clips slightly — that asymmetry is part of Q4_0.
  • Q4_K style super-block — 256 weights → 136 bytes. 8 groups of 32. Group sub-scale r = amax/8; super-scale d = FP16(max r / 63); each r is stored as a 6-bit code k = clamp(round(r/d), 0, 63) (8 × 6 bits = 6 bytes); the group scale is e = d·k, then nibbles as above. Layout: 2 B (d) + 6 B (k) + 128 B (nibbles).
  • FP16. The scale is rounded to IEEE-754 half precision before use and shown as hex; dequantization uses the rounded value, like real hardware.
  • Loss. MSE = mean((ŵ − w)²) over the input weights, RMSE = √MSE, SQNR = 10·log10(Σw² / Σerr²). FP32 needs 4 bytes per weight; Q4_0 stores 4.5 bits/weight, Q4_K style 4.25.
