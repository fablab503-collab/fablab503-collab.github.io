Memory Defrag Simulator

Simulate memory fragmentation and defragmentation for large model loading.

Memory Layout

Allocated: 0 Fragmented: 0 Free: 0

How It Works

This simulation shows how memory fragmentation occurs when loading large models and how defragmentation can help.

  • Green cells: Allocated memory blocks
  • Red cells: Fragmented memory (small free blocks)
  • Blue cells: Defragmented memory (large contiguous blocks)
