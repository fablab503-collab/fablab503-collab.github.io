How it works

  • Absmax: scale = max|w| / 127, zero-point = 0.
  • Zero-point: scale = (max − min) / 255, zero-point = clamp(round(−128 − min/scale), −128, 127).
  • Each weight is stored as q = clamp(round(w / scale) + zero-point, −128, 127) — one INT8 value.
  • Dequantized value: ŵ = (q − zero-point) × scale. Error = ŵ − w.
