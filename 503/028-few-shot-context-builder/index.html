Few Shot Context Builder

Type your query and this page picks the best matching examples from the local dataset (TF-IDF cosine similarity), then assembles a ready-to-paste few-shot prompt. Drag example cards to pin and reorder them, or drop a .json, .csv or .txt file to import your own examples. Everything runs offline in your browser.
