How It Works

This demo simulates thermal throttling. As the simulated CPU load increases, temperature rises and performance decreases.

Thresholds: Normal (≤ 65°C), Warning (65-75°C), Critical (> 75°C)

Note: This is a simulation. Actual thermal throttling depends on hardware capabilities.
