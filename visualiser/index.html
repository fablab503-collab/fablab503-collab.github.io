Visualiser

Paste a GitHub link and see the project as if you had downloaded it: the page running live, every file, the code and the README. Nothing is downloaded or installed on your computer.

Collez un lien GitHub et voyez le projet comme si vous l'aviez téléchargé : la page qui tourne en direct, tous les fichiers, le code et le README. Rien n'est téléchargé ni installé sur votre ordinateur.

Try:Essayez :
1. Paste a link1. Collez un lien

Any public repository: github.com/owner/repo, a branch, a folder or a single file.

N'importe quel dépôt public : github.com/owner/repo, une branche, un dossier ou un fichier.

2. See it run2. Voyez-le tourner

HTML, CSS and JavaScript projects open live, in a sealed sandbox, on desktop, tablet or phone size.

Les projets HTML, CSS et JavaScript s'ouvrent en direct, dans un bac à sable isolé, en taille ordinateur, tablette ou téléphone.

3. Read the code3. Lisez le code

Browse the file tree, open any file with syntax colours, and read the README.

Parcourez l'arborescence, ouvrez n'importe quel fichier avec la coloration du code, et lisez le README.

Projects that must be built first (React with Vite, Next.js, Python, apps) cannot run in a browser as they are; Visualiser then shows their files and README, and their gh-pages branch when there is one. Public repositories only, about 20 projects per hour (GitHub limit without an account).

Les projets qui doivent d'abord être compilés (React avec Vite, Next.js, Python, applications) ne peuvent pas tourner tels quels dans un navigateur ; Visualiser montre alors leurs fichiers et leur README, et leur branche gh-pages s'il y en a une. Dépôts publics uniquement, environ 20 projets par heure (limite GitHub sans compte).
